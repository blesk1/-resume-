# Интерактивное резюме Максима Замуруева

## Публикация на GitHub Pages
1. Войдите в свой GitHub и создайте новый публичный репозиторий `resume`.
2. Распакуйте архив. Загрузите содержимое папки сайта (не ZIP) в корень репозитория через Add file → Upload files. Файл index.html должен лежать в корне.
3. Сохраните изменения (Commit changes) в ветке main.
4. Откройте Settings → Pages. В Source выберите Deploy from a branch, затем main и /(root). Нажмите Save.
5. Дождитесь публикации и откройте адрес через Visit site. Скопируйте фактический адрес, показанный GitHub.
6. Откройте адрес в приватном окне без входа в GitHub. Проверьте разделы, обе демонстрации, добавление и удаление записей, изменение остатков и статусов, почтовую ссылку, печать.
7. Сделайте снимки всей страницы с перекрытием и добавьте их вместе с адресом сайта в отчёт Word. Не выдавайте локальный просмотр за проверку опубликованного сайта.

Документация: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

## Состав
index.html — резюме; style.css — оформление; logistics.html и warehouse.html — учебные демонстрации; demo.js — общий код демонстраций.

## Что проверить перед публикацией
Навыки 4–6 и описания проектов предложены для заполнения учебного портфолио. Уточните их под свой реальный опыт. Два прототипа подготовлены специально для этой страницы и не подтверждают наличие ранее реализованных полноценных систем. Курс и специальность не указаны: добавьте достоверные сведения в раздел образования.

Сайт содержит согласованный адрес электронной почты. Паролей, аналитики и внешних библиотек нет. Данные демонстраций сохраняются на устройстве пользователя. При печати можно выбрать «Сохранить как PDF».
